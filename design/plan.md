# 한글 받아쓰기 사격 게임 — 기획서 v0.1

**한 줄 요약:** 문제를 소리로 듣고, 1인칭 시점에서 떠다니는 글자 풍선을 **순서대로 쏴서** 문장을 완성하는 받아쓰기 FPS.
**대상:** 초등 저학년(가정) · **플랫폼:** PC 브라우저(마우스) · **기술:** Astro + Three.js(npm 번들)

## 게임 흐름

1. 시작 화면 → [게임 시작] / [문제 올리기]
2. 문항 시작: 음성(TTS, ko-KR)으로 문제를 읽어줌. 화면에는 글자 수만큼 빈칸 `□□□ □□□□`
3. 하늘에 글자 풍선 등장(정답 음절 + 헷갈리는 오답 음절). 다음 빈칸에 들어갈 글자를 쏜다
4. 빈칸을 모두 채우면 정답 연출 → 다음 문항. 10문항 후 결과 화면(별점·틀린 글자 복습)

띄어쓰기는 자동 처리(빈칸 사이 간격으로만 표시), 문장부호는 자동 입력.

## ① 오브젝트 목록

| 이름 | 역할 | 비고 |
|---|---|---|
| 플레이어(물총) | 고정 위치에서 마우스로 조준·발사 | 이동 없음(멀미·조작 난이도 방지), 시야 좌우 ±60° 상하 ±30° |
| 글자 풍선 | 음절 1자가 적힌 표적 | 천천히 떠다님, 한 번에 6~8개 |
| 정답 풍선 | 다음 빈칸의 글자 | 맞히면 터지며 빈칸에 날아가 채워짐 |
| 오답 풍선 | 헷갈리는 글자 | 맞히면 "뿅" 흔들리고 유지, 하트 -1 |
| 물방울 탄 | 발사체(즉시 판정 + 시각 효과) | 탄약 무제한, 연사 0.3초 간격 |
| 배경 | 낮은 폴리곤 놀이공원 하늘 | 폭력적 표현 없음(물총·풍선) |

**오답 글자 생성 규칙:** 정답 음절의 자모를 분해해 받침·모음을 바꾼 유사 음절(예: `갑`→`갚/값/감`, `에`→`애`, `되`→`돼`) + 같은 문장의 다른 음절.

## ② 점수 · 진행 규칙

- 정답 글자 +10점, 연속 정답 콤보 시 +2씩 추가(최대 +10)
- 문항당 하트 3개. 오답 시 -1. 0이 되어도 **게임오버 없음** → 정답 풍선이 반짝이는 힌트 모드로 전환(해당 문항 별 1개)
- 문항 별점: 오답 0회 ★★★ / 1~2회 ★★ / 그 외 ★
- 시간 제한 없음. `R` 또는 스피커 버튼으로 다시 듣기(무제한)
- 결과 화면: 총점, 별 합계, 틀렸던 글자와 정답 문장 목록

## ③ 표적 행동 (적 AI 대신)

- 풍선은 플레이어 전방 반구(거리 12~20m)에 배치, 초당 0.3~0.6m로 상하·좌우 부유
- 정답을 맞히면 다음 빈칸용 풍선이 부족할 때 1초 내 보충 → 화면에 항상 "다음 정답" 1개 이상 존재
- 같은 글자가 문장에 여러 번 나오면 풍선도 그만큼 따로 등장
- 15초간 정답을 못 맞히면 정답 풍선이 살짝 반짝임(자동 힌트)

## ④ 조작

| 입력 | 동작 |
|---|---|
| 마우스 이동 | 조준(화면 클릭 시 포인터 잠금) |
| 좌클릭 / Space | 발사 |
| R | 문제 다시 듣기 |
| Esc | 일시정지(포인터 해제) |

**모바일·태블릿(터치):** 풍선을 **직접 탭하면 그 자리로 발사**, 화면을 끌면 시야 이동. 화면의 🔊·⏸ 버튼으로 다시 듣기·일시정지. 가로·세로 화면 모두 지원(세로에서는 시야각을 넓히고 풍선 6개로 축소), 모든 풍선은 기본 시야 안에 배치. 마우스 포인터 잠금이 안 되는 환경에서도 클릭한 자리로 발사.

## ⑤ 화면 구성

- 상단 중앙: 빈칸 진행판 `학 교 □ □ □ □`
- 상단 좌: 문항 번호 `3 / 10`, 하트 / 상단 우: 점수, 콤보
- 중앙: 조준점 / 하단: 물총, 다시 듣기 버튼
- 오버레이: 시작, 일시정지, 문항 정답 연출, 결과

## 문제 업로드 (10문항)

- 기본: `src/data/questions.json`에 샘플 10문항 내장 → 나중에 이 파일만 교체하면 됨
- 게임 내 [문제 올리기]: `.txt`(한 줄에 한 문제) 또는 `.json` 파일 선택 → 브라우저(localStorage)에 저장되어 다음에도 유지, [기본 문제로 되돌리기] 제공
- 형식: `["학교에 갑니다.", "꽃이 피었습니다.", ...]` — 문항 수는 10개 기준이나 1~30개 허용
- 음성: 브라우저 내장 한국어 TTS 사용(추가 녹음 파일 불필요). 원하면 문항별 mp3 지정 가능하도록 확장 여지

## v0.3 — 반복 학습(바퀴) · 단계 · 상점

- **바퀴 규칙:** 1번~마지막 문항을 한 바퀴로 본다. 1단계(받아쓰기)는 오답 풍선을 한 번도 맞히지 않을 때까지 1번부터 반복한다.
- **단계:** ① 받아쓰기(완벽해야 통과) → ② 빈칸 채우기(받침 있는 글자 위주로 비움) → ③ 번개 받아쓰기(제한 시간 안에 끝내면 코인 보너스) → 왕관, 다시 ①부터.
- **반복 보상:** 바퀴 완료 10, 끈기 보상(바퀴째×5, 최대 50), 지난번보다 덜 틀리면 +10, 완벽 +50, 왕관 +100. 맞힌 글자마다 +1(5연속마다 +3).
- **난이도(1~5):** 풍선 수·떠다니는 속도·자동 힌트 시간. 완벽하면 +1, 8번 이상 틀리면 -1.
- **배경:** 바퀴마다 봄 → 노을 → 밤 축제 → 겨울 → 우주 순으로 바뀐다.
- **상점:** 물총 색 6종, 물줄기 4종, 터지는 효과 5종. 코인으로 사고 바로 장착.
- **문제 교체:** 문제 묶음이 바뀌면 단계·바퀴만 처음으로, 코인·아이템은 유지.
- 로직은 `src/scripts/campaign.ts`(순수 함수, `tests/logic.test.ts`로 검증).

## v0.4 — 최종 시험(손글씨 보스전) · 학생 계정 · 명예의 전당

- **최종 시험:** 사격 3단계(받아쓰기 → 빈칸 → 번개)를 모두 지나면 4단계 `🐉 최종 시험`. 문제를 듣고 **화면에 손가락·마우스로 글자를 직접 써서** 되찾는다. 보스 "글자 도둑 대왕"의 체력 = 전체 글자 수. 글자를 맞게 쓰면 체력 -1, 틀리게 쓰면 보스의 공격(하트 -1, 화면 흔들림), 글자마다 제한 시간이 있고 넘기면 공격. 체력 50%·25%에서 분노 단계(얼굴·색이 바뀌고 시간이 짧아진다). 하트 0이면 연한 글자를 따라 쓰는 힌트. 끝내면 왕관 + 등급(S 0회 / A ≤2 / B ≤5 / C) + 코인.
- **손글씨 인식:** 브라우저 안의 Tesseract(한국어, `public/tesseract`)로 한 글자씩 읽는다(`ocr.ts` `readHandwriting`, 한 단어 모드 PSM 8). 쓴 획만 잘라 캔버스의 80% 크기로 맞춘 뒤 읽고(`normalizeHandwriting`), 읽힌 글에 정답 글자가 들어 있으면 정답. 못 읽은 글자는 벌점 없이 "크게 또박또박" 안내. 인식 엔진을 못 띄우면 키보드 입력으로 대체. 보스 등장 연출 동안 엔진을 미리 띄운다.
- **학생 계정:** 시작할 때 이름·비밀번호(2자 이상). 처음 이름이면 새로 만들기 확인, 있는 이름이면 비밀번호로 로그인. 계정마다 진행(단계·코인·아이템·기록)을 따로 저장(`users.ts`, localStorage `dictation.users.v1`, 비밀번호는 SHA-256 해시만 보관). 첫 계정은 이전 버전의 진행을 이어받는다. 메뉴의 [바꾸기]로 다른 학생으로 교체.
- **명예의 전당·자랑하기:** 이 기기의 모든 학생을 명예 점수(왕관×500 + 최종 시험 최고점 + 최고 점수)로 줄 세운다. [자랑하기]는 자랑 카드(그림)와 글·링크를 만들어 공유창(Web Share)으로 보내거나 복사한다. 링크(`#brag=…`)를 연 친구의 명예의 전당에는 보낸 사람의 기록이 👫 친구로 들어가 서로 비교할 수 있다. 서버 없이 동작(기록은 기기와 링크로만 공유).
- 로직은 `campaign.ts`(`finishBoss`, `bossTime`, `gradeOf`), `users.ts`, `sha256.ts` — `tests/*.test.ts`로 검증.

## v0.5 — 상점 확장 · 난사 경고 · 우승자 명단 · 스티커 배경

- **상점:** 물총 10종(크기 0.7~1.85배, 큰 물총은 화면 모서리로 밀려 총구만 커 보인다) · 물줄기 7종(색·굵기, 반짝이) · 터지는 효과 8종(이모지 입자, 퍼지는 고리, 덤 불꽃놀이, 화면 흔들림). 가격 120~3000코인으로 올려 천천히 모으게 했다. 각 종류의 마지막(👑 전설의 용 물총 3000 · 용의 숨결 2000 · 용의 불꽃 2500)이 가장 비싸고 가장 화려하다(금속 광택 + 무지개 색 순환 + 총구 기운 + 뿔, 반짝이 물줄기, 불꽃 고리 + 불꽃놀이 + 흔들림).
- **난사 경고:** 6초 안에 빗나가거나 틀린 사격이 6번이면 "아무 데나 쏘지 말아요" 경고와 함께 3초 동안 사격이 잠기고 문제를 다시 읽어 준다. 두 번째 경고부터 코인 5개를 잃는다(게임 오버는 없음). 결과 화면에 경고 횟수를 보여 준다. 규칙은 `campaign.ts` `recordBadShot`/`applyWarning`.
- **우승자 명단:** 최종 시험을 통과할 때마다 우승 기록 `{회차, 바퀴 수, 등급, 점수, 시각}`을 남긴다. **우승 점수** = 빠르기(최소 4바퀴 = 5000, 바퀴마다 -500, 최저 500) + 등급(S 300/A 200/B 100/C 0) + 시험 점수÷20(최대 99). 바퀴 하나 차이가 등급+점수보다 커서 **적은 바퀴로 우승한 학생이 언제나 위**이고, 같은 바퀴면 등급, 그다음 점수 순. 우승 점수가 같으면 공동 순위(1·1·3위). 명예의 전당 [🔗 전체 보내기]는 우승자 전원을 한 링크(`#hall=…`)에 담아 다른 기기에서도 볼 수 있게 한다. 자랑 링크에도 우승 기록이 들어간다.
- **스티커 배경:** 학생이 모은 스티커(동물 이모지)를 잔디밭 곳곳에 세운다(`scene.ts` `setStickers`, 같은 스티커는 늘 같은 자리). 학생마다 모은 스티커가 달라 배경이 달라 보인다.
